# CentralFix

Sitio de servicios de reparación con formulario de consultas y acceso administrativo para gestionarlas.

**Stack de la implementación local:** HTML, CSS y JavaScript, con Supabase para datos y acceso.

Este repositorio contiene la presentación pública del proyecto. El código y la configuración operativa no están publicados aquí. No se incluye una demo porque no se verificó una URL pública vigente.
